# Installing and updating All of my Irons in the Fire!

Use these steps to walk a user through installing or updating. Give one step at a time if they're doing it live, and wait for "done" before the next.

## Before you start

- **This needs a computer.** Plugins are added in Claude on the web (claude.ai) or the Claude desktop app. The Claude phone app can't install a plugin from a file.
- If the user is on a phone or driving, don't start. Say it needs a computer, and save "Update All of my Irons in the Fire!" to `later-list`.
- Never ask the user to sign out of anything, share a password, or let anyone else into their account. Installing never needs that.

## Steps

1. **Download the plugin file.** On the computer, open https://github.com/MindfulTechSupport/All-of-the-Irons-in-the-Fire-App-/releases/latest and click the file ending in `.plugin` (for example `all-my-irons-in-the-fire-v0.6.0.plugin`). It saves to the Downloads folder.
2. **Open Claude** on that computer: the desktop app or claude.ai in a browser.
3. **Go to Customize, then Plugins**, in the left sidebar.
4. **If an older version is listed, remove it first**, so there aren't two copies. Their irons map is kept in Claude's memory or their folder, not in the plugin, so nothing is lost.
5. **Upload the new `.plugin` file.**
6. **Check it worked:** start a new chat and say "fire up." The greeting should match the time of day. They can also ask "what version of All of my Irons in the Fire! am I on?"

## If something goes wrong

- **Can't find the upload option:** the Customize screen may differ by plan or app version. Suggest trying claude.ai in a browser.
- **Nothing happens after upload:** start a brand-new chat; existing chats may not pick up a new plugin.
- **Still stuck:** point them to the repository's README and https://support.claude.com.
